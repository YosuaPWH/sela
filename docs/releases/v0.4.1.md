Sela 0.4.1 fixes the game-only gaming line and makes Sela easier to reach.

- Fixed: without capture permission (Sela not run as administrator), the game-only gaming line never appeared. Detection now falls back to the fullscreen check when frames cannot be captured.
- Fixed: the gaming line stayed visible after a game closed while Sela was focused.
- Fixed: marking a game restarted capture, resetting readings and stopping a benchmark.
- Fixed: a style saved for one app replaced the default style and carried over to other apps. The style choice now edits the captured app's saved style; **Use default style** removes it.
- Launching Sela again opens the running instance's panel instead of doing nothing.
- Left-click the tray icon to open or close the panel; right-click for the menu.
- In game-only mode, only fullscreen or marked applications are captured, so switching between ordinary apps no longer starts PresentMon. Mark windowed games from **Games → Mark a running app…**.
- Settings are saved shortly after a change instead of on every frame while dragging a slider. Game-only mode starts on the Media tab.

Download **Sela-0.4.1-setup-x64.exe** to install, **Sela-0.4.1-windows-x64.zip** for portable use, or **sela-notch.exe**. **SHA256SUMS.txt** contains download hashes. Builds are unsigned.
