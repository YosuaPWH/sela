- Added original English demo lyrics and updated the gallery with native English screenshots.

Download **Sela-0.2.1-setup-x64.exe** for a per-user installation, or use **Sela-0.2.1-windows-x64.zip** / **sela-notch.exe** for portable use. **SHA256SUMS.txt** contains hashes for the binary downloads. The installer and app are unsigned.
