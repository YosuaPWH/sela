Sela's first tagged release: a native Rust notch for Windows, with Pijar the firefly.

- Windows media controls and synchronized lyrics from LRCLIB.
- A collapsed music view with the song title on the left and one centered lyric line on the right.
- Contextual, left-aligned lyrics in the expanded panel, plus plain, unavailable, and instrumental states.
- Continuous spring motion and a reduced-motion option.
- Focus sessions, on-demand CPU/RAM readings, and battery status when available.
- Local settings and lyric caching, plus an explicitly labelled offline demo.

## Install

Download **Sela-0.2.0-setup-x64.exe** and run the installer. It installs for the current user, adds a Start Menu shortcut, and includes an uninstaller. Administrator privileges are not required.

For portable use, extract **Sela-0.2.0-windows-x64.zip** or download **sela-notch.exe** directly. **SHA256SUMS.txt** contains hashes for all three files.

Requires Windows 10 version 1809 or later / Windows 11, x64, with an OpenGL 2.0+ driver. The app and installer are unsigned. Windows desktop integration still requires direct device testing; CI checks the build, core logic, and installer lifecycle.

Lyrics are optional. When enabled, the title, artist, and duration are sent to LRCLIB over HTTPS. The app UI currently uses Indonesian labels; the README is in English.
