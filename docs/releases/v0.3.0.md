Sela adds native performance monitoring with a single-line gaming overlay.

- Open **System → Performance**, enable **Show gaming performance line**, then choose **Text only** or **With background**. Both keep FPS, RAM, VRAM, GPU/CPU readings, frame time and 1% low visible without opening the panel.
- The closed gaming line is click-through, stays closed on hover, and opens through **Ctrl+Alt+N** or the tray.
- PresentMon 2.6.0 is embedded in official binaries. Select the foreground application or a visible application process. Capture permissions may require administrator or Performance Log Users access.
- CPU/RAM use system readings. Windows GPU counters provide fallback GPU/VRAM data; supported NVIDIA drivers add NVML temperature and power. Unsupported sensors, including CPU temperature, show unavailable values.
- Save a style per executable, inspect frame-time history, record 15/30/60-second benchmarks, compare sessions, and export captured frame times as CSV/JSON.
- Capture keeps PIDs and swap chains separate, rejects stale data, and shuts down its provider with monitoring. Legacy settings remain compatible.

See the [performance guide](https://github.com/YosuaPWH/sela/blob/main/docs/PERFORMANCE.md) for metric definitions, permissions and compatibility. Borderless/windowed games are recommended; exclusive fullscreen and anti-cheat compatibility vary. There is no overclocking, fan control or frame-rate cap.

Download **Sela-0.3.0-setup-x64.exe** to install, **Sela-0.3.0-windows-x64.zip** for portable use, or **sela-notch.exe**. All official binaries contain the frame provider. **SHA256SUMS.txt** contains download hashes. Builds are unsigned.
